Join a table

No server required — this uses WebRTC to connect players directly to each other. The only outside service involved is PeerJS's free public broker, used once just to introduce two browsers to each other; every card, bet, and move after that travels peer-to-peer. One player creates a table and shares the room code; everyone else joins with that code. If the table creator closes their tab, the table ends — there's no host handover.

To create with your own code, type it above before hitting "Create Table" — leave it blank and one is generated for you. To join, enter the exact code the host is using.
